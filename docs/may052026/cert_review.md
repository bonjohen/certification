Five recommended additions
Selection rule. These are popular, broadly useful exams that are not represented as clear site items today and that fill visible gaps in the current catalog.
Recommended test	Why it should be added	Lifecycle/timeframe note
AWS Certified Solutions Architect - Professional (SAP-C02)	Adds the natural professional-level continuation after SAA-C03. It is one of the strongest AWS architecture signals and fits users who finish the associate path.	Professional exam; 180 minutes; 75 questions; $300; current official AWS exam guide page.
Google Cloud Professional Data Engineer	The site has GCP data training material, but not the named proctored Data Engineer certification. This fills a clear data-engineering gap and matches the site audience.	Official Google page states a 2-hour, $200 exam, 40-50 questions, and 2-year validity.
Microsoft Certified: Fabric Analytics Engineer Associate (DP-600)	Modern Microsoft analytics work has shifted toward Fabric, lakehouse, semantic models, and Power BI integration. This complements DP-900 and adds a practical data-platform path.	Microsoft describes the role around preparing/enriching data, securing and maintaining assets, and managing semantic models.
GitHub Copilot Certification (GH-300)	Directly relevant to AI-assisted development, coding workflows, and prompt engineering. It would complement the site’s AI tracks and make the catalog feel current.	GitHub lists Copilot certification content around responsible AI, prompt engineering, privacy/exclusions, testing, and developer use cases.
GitHub Actions Certification (GH-200)	Adds CI/CD automation coverage. It complements AZ-400, AWS Developer, and CloudOps/SysOps material and supports the practical build-deploy side of certification prep.	GitHub describes the Actions certification as covering workflow automation, task automation, and pipeline optimization.
Implementation notes
•	Use explicit status badges: Current, Ending Soon, Retired, Training Only, and Source Needed.
•	For Microsoft, show whether a certification is fundamentals/non-expiring or role-based/specialty with annual renewal.
•	For AWS, show the standard three-year certification validity and the active exam code.
•	For Google Cloud, distinguish professional/foundational certifications from Skills Boost courses and exam-prep pages.
•	Keep stale certification pages for SEO only if they clearly redirect users to the replacement exam.
