## Professional Certifications

### Currently Available

| Certification | Code | Status | Cost | Format |
|---|---|---|---|---|
| Claude Certified Architect — Foundations | CCA-F | Live (Mar 2026) | Free for partners / $99 non-partners | 60 questions, proctored on Skilljar |

CCA-F covers 5 domains:
1. Agentic Architecture & Orchestration (27%)
2. Claude Code Configuration & Workflows (20%)
3. Tool Design & MCP Integration (18%)
4. Prompt Engineering & Structured Output (20%)
5. Context Management & Reliability (15%)

## Anthropic Academy (Free Training)

Launched March 2, 2026 on anthropic.skilljar.com. All courses are free, self-paced, and award official Anthropic certificates valid on LinkedIn.

### Course Catalog (17 courses as of April 2026)

Organized into 5 learning tracks:

#### AI Fluency (No-Code)
- Claude 101
- AI Fluency for Everyone
- AI Fluency for Students
- AI Fluency for Educators/Faculty
- AI for Nonprofits

#### Developer & Technical
- Building with the Claude API (~8+ hours, core developer course)
- Claude Code in Action
- Intro to MCP (Model Context Protocol)
- MCP Advanced Topics
- Building MCP Servers (Python, tools/resources/prompts primitives)
- Agent Skills (creating and sharing Skills in Claude Code)
- Sub-Agents in Claude Code

#### Cloud & Enterprise
- Claude on AWS
- Claude on Google Cloud

#### Recommended Developer Learning Path
```
Claude 101 → Building with the Claude API → Claude Code in Action → Intro to MCP → MCP Advanced Topics → Agent Skills
```

## Relevance to This Project

Currently only CCA-F has a formal exam format suitable for a question bank. The Anthropic Academy courses provide completion certificates but are course-based (not exam-based), so they aren't directly applicable to our quiz format.

When the advanced certifications launch (CCA-Advanced, Developer, Seller), those would be candidates for new XML question banks.
